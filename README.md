# mac-mktg-setup

A restore kit for my machine. Not a tutorial — a record of what this Mac is, kept
current enough that wiping it is a Tuesday afternoon instead of a lost weekend.

Forked long ago from [michaelschwobe/mac-dev-setup](https://github.com/michaelschwobe/mac-dev-setup),
then rebuilt around a different problem. That repo assumed a front-end developer.
This one assumes someone who lives in Adobe, Obsidian, a terminal, a local model
runner, and about forty small utilities that each do one thing.

---

## The shape of it

A clean install has two halves, and only one of them is about software.

**Software** is solved. Homebrew reinstalls sixty apps in one command, and the
list of those apps should be *generated from the machine*, never typed by hand —
a hand-maintained list is wrong the day after you write it.

**State** is the hard half. Fonts, the Obsidian vault and its `.obsidian`
config, Lightroom presets, shell history, license keys, macOS defaults you set
once in 2021 and forgot. None of that comes back from a package manager, and
none of it belongs in a public repo.

So the repo runs in two directions:

```
capture.sh   →   run BEFORE the wipe. Reads the machine, writes it down.
install.sh   →   run AFTER the wipe.  Reads what was written, rebuilds.
```

And it writes to two destinations, which is the important part:

| | goes to | contains | in git? |
|---|---|---|---|
| **Manifests & config** | this repo | Brewfiles, plugin lists, dotfiles, extension lists | yes |
| **Archive** | `Mnemosyne:/archive/mac-restore/` | tarballs, vaults, catalogs, secrets | **never** |

If it identifies you or costs money to replace, it lives on the NAS. If it's a
list of things that can be re-downloaded, it lives here.

## Layout

```
capture/
  capture.sh              run before the wipe — the whole point of this repo
install/
  install.sh              orchestrator
  00-preflight.sh         Xcode CLT, Homebrew, Rosetta, ~/Developer
  10-defaults.sh          macOS defaults I actually changed on purpose
  20-brew.sh              brew bundle install, by tier
  30-restore.sh           pull the archive back down off the NAS
  90-summary.sh           what worked, what still needs hands
brewfiles/
  Brewfile.core           shell, terminal, utilities — always
  Brewfile.creative       Adobe, fonts, color, design
  Brewfile.media          Roon, TIDAL, readers, players
  Brewfile.ai             LM Studio, Stability Matrix, Docker, model runners
  Brewfile.work           Office, Teams, Webex, VPN — skip on a personal box
  Brewfile.captured       ← generated by capture.sh. Truth. Split it into the above.
manifests/                generated, committed, human-readable
  orphan-apps.txt         apps brew doesn't know about ← read this first
  fonts.txt
  obsidian.md             plugins, themes, snippets, core plugin states
  vscode-extensions.txt
  models.md
config/
  shell/                  .zshrc, .zprofile, .p10k.zsh, .gitconfig
  vscode/                 settings.json, keybindings.json, snippets
tools/
  triage-links.py         bookmark/tab dedupe + link rot → Obsidian Markdown
docs/
  RESTORE.md              the manual steps, in order
  MANUAL.md               things no script will ever handle
```

## Before the wipe

```bash
git clone https://github.com/djenders/mac-mktg-setup.git ~/Developer/mac-mktg-setup
cd ~/Developer/mac-mktg-setup/capture
./capture.sh
```

Sections can run individually: `./capture.sh brew fonts obsidian`.

Then, in order:

1. **Read `manifests/orphan-apps.txt`.** Every app there is one the installer
   won't bring back. Either find a cask for it, add it to `docs/MANUAL.md`, or
   admit you don't use it.
2. **Split `Brewfile.captured`** into the tiered Brewfiles. Ten minutes, once.
3. **Do the manual exports** — see `docs/MANUAL.md`. Evernote first; it's the
   only step on the list that can't be redone after the wipe.
4. **Ship the archive**, then verify it landed intact:
   ```bash
   rsync -avh --progress ~/Desktop/mac-restore-*/ Mnemosyne:/archive/mac-restore/2026-08/
   ssh Mnemosyne 'cd /archive/mac-restore/2026-08 && shasum -a 256 -c SHA256SUMS'
   ```
   Unverified backups aren't backups.
5. **Commit.** `git add manifests brewfiles config && git commit -m "capture $(date +%F)"`
6. **Take a Time Machine backup** — and then don't migrate from it. Migration
   Assistant will happily restore every piece of cruft you're wiping to escape.
   TM is the rollback, not the restore.

## After the wipe

```bash
xcode-select --install
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

git clone https://github.com/djenders/mac-mktg-setup.git ~/Developer/mac-mktg-setup
cd ~/Developer/mac-mktg-setup/install
./install.sh
```

Then restore by tier:

```bash
brew bundle install --file=../brewfiles/Brewfile.core
brew bundle install --file=../brewfiles/Brewfile.creative
# …only the tiers this machine needs
```

Sign in to Adobe CC before restoring fonts — Adobe's own fonts re-sync on their
own, and restoring them from the tarball just creates duplicates in Font Book.

## Rules this repo keeps

- **Generated beats maintained.** If a list can be derived from the machine, it
  is. The old `casks.sh` kept app names and descriptions in two parallel bash
  arrays that had to stay index-aligned by hand. That's how it drifted.
- **Nothing personal in git.** This repo is public. `.ssh`, license keys, browser
  profiles, and vault contents go to the NAS, encrypted.
- **Rotate rather than migrate.** SSH keys and API tokens get regenerated on the
  new machine. A wipe is the cheapest possible key rotation — use it.
- **Manual steps are written down, not remembered.** `docs/MANUAL.md` is as
  load-bearing as any script here.
