# Brewfiles

Tiered so a restore installs only what a given machine needs.

| file | when |
|---|---|
| `Brewfile.core` | always |
| `Brewfile.creative` | Adobe + design work |
| `Brewfile.media` | music, comics, games |
| `Brewfile.ai` | local models, Docker |
| `Brewfile.work` | GMR stack — check MDM first |
| `Brewfile.finance` | wallets, tax |
| `Brewfile.captured` | generated by capture.sh. Truth, unsorted. Never edit. |

```bash
brew bundle install --file=brewfiles/Brewfile.core
```

## Reconcile before the next capture

Three things brew currently believes that aren't true:

```bash
brew uninstall --cask chatgpt      # registered, but the app isn't in /Applications
brew uninstall --cask ledger-live  # duplicate of ledger-wallet
brew uninstall watchman            # upstream fork residue; React Native file watcher
brew uninstall node@20 nvm         # three-way node conflict; node@20 EOL Apr 2026
```

And check what depends on the EOL Python before removing it:

```bash
brew uses --installed python@3.9
```

If only `pipx` shows up, reinstall pipx against current Python first, then prune.

## What is deliberately not here

`scripts/casks.sh` — deleted. It maintained app names and descriptions in two
parallel bash arrays that had to stay index-aligned by hand, and it had drifted
in both directions: it claimed to install Adobe CC, MonitorControl and PIA
(brew has none of them) while knowing nothing about Docker, GitHub Desktop,
VS Code, Stillcolor, rar, or ledger-wallet (brew has all of them).
